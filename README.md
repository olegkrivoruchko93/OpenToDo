# OpenToDo

OpenToDo — веб-приложение для управления личными задачами. Проект написан на Flask и хранит данные в локальной базе SQLite.

## Возможности

- регистрация и вход пользователей;
- создание, редактирование и удаление задач;
- описание задач, сроки выполнения и статусы готовности;
- группировка задач по проектам с иконками;
- метки с цветами и фильтрация по ним;
- чеклисты внутри задач;
- прикрепление файлов к задачам;
- представления «Входящие», «Сегодня», «Планы» и «Корзина»;
- экспорт и импорт резервных копий в JSON и CSV ZIP.

## Технологии

- Python;
- Flask;
- Flask-SQLAlchemy;
- SQLite;
- HTML и CSS.

## Установка

1. Создайте и активируйте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Установите зависимости:

```powershell
pip install -r requirements.txt
```

## Запуск

```powershell
python app.py
```

После запуска приложение будет доступно в браузере по адресу `http://localhost:5000`.

При первом запуске приложение автоматически создаст базу данных `todo.db` и необходимые таблицы.

## Настройки окружения

Дополнительно можно задать переменные окружения:

- `SECRET_KEY` — секретный ключ Flask-сессий;
- `FLASK_DEBUG=1` — включение debug-режима;
- `FLASK_TEMPLATES_AUTO_RELOAD=1` — автообновление шаблонов;
- `SESSION_COOKIE_SECURE=1` — отправка cookie только по HTTPS;
- `FLASK_RUN_HOST` — хост для запуска приложения.
